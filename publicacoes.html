/* ========================================================= PUBLICACOES — CARREGAR NA PAGINA ========================================================= */ async function loadPosts() { const containers = qsa( "#postsGrid", "#publicacoesGrid", "#publicacoesLista", "#publicationsList", "#publicacoesContainer" ); if (!containers.length) return; if (!isSupabaseReady()) { containers.forEach((container) => { container.innerHTML = '
O sistema de publicações não está disponível.
'; }); return; } try { let query = supabase .from(TABLES.PUBLICACOES) .select( "id,titulo,resumo,conteudo,imagem_capa,publicado,data_publicacao,criado_em" ) .eq("publicado", true); // Na página inicial, mostrar apenas seis publicações. if (getCurrentPage() === "index.html") { query = query.limit(6); } const { data, error } = await query.order( "data_publicacao", { ascending: false, nullsFirst: false } ); if (error) throw error; containers.forEach((container) => { if (!data || data.length === 0) { container.innerHTML = '
Nenhuma publicação disponível no momento.
'; return; } container.innerHTML = data.map((post) => `
${ post.imagem_capa ? ` ` : `
Max Som
` }
Publicação Max Som

${esc(post.titulo || "Publicação")}

${ post.resumo ? `

${esc(post.resumo)}

` : "" } ${ post.data_publicacao ? `${esc(formatDate(post.data_publicacao))}` : "" } ${ post.conteudo ? `
Ler publicação

${esc(post.conteudo)}

` : "" }
`).join(""); }); } catch (error) { console.error("Erro ao carregar publicações:", error); containers.forEach((container) => { container.innerHTML = '
Não foi possível carregar as publicações. Verifique a conexão com o banco de dados.
'; }); } }
